Publish approved arcade scores

Free Play scores are recorded on each student's device. To publish an approved three-letter score on the class-wide board, edit arcade-class-highscores.json on GitHub, add an entry such as {"initials":"ABC","score":12000}, then commit your change. The public class leaderboard updates on deployment.

Only GitHub accounts with repository write access can update these records. Scores are not automatically submitted, and a local score slip alone is not tamper-proof.

Label files by unit

Start the filename with unit-01-- to list it under Unit 1. For example, unit-01--Definite articles.pdf appears as “Definite articles.” Files for the whole course can keep their usual names.

To pair a slide deck with its PDF preview, give both files the same name before the extension.
